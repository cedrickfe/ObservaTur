# AGENTS.md

## Objetivo
Manter consistência visual e estrutural do front-end ObservaTur.

## Diretrizes rápidas
- Tecnologias: Next.js (App Router) + TypeScript + Tailwind.
- Não implementar backend, banco, autenticação real ou integração com API externa.
- Usar dados mockados em `src/data`.
- Priorizar UI clara: fundo branco, bordas arredondadas, borda cinza clara, hover em tons de cinza.
- Criar componentes reutilizáveis em `src/components/ui` antes de duplicar código.
- Componentes de domínio devem ficar em `src/components/domain`.
- Manter tipagens de negócio em `src/types`.
- Garantir responsividade mobile/tablet/desktop em todas as telas.
